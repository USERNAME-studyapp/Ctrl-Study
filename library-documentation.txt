    UInt(name, minValue, maxValue)
        - Generates a number randomly between min and maxValue (inclusive).
        - Given no arguments, defaults to name="value", minValue=0, and maxValue=100
    LoopInt(name, startMin, startMax, endMin, endMax, stepMin, stepMax, allowDecrement)
        - Randomizes loop start/end/step using the provided bounds.
        - Creates a LoopIntValue with fields: name, start, end, step, operator, values, current.
        - iterations equals the length of values (values are generated with range(start, end, step)).
        - allowDecrement=True permits negative step values.
charGen(*exclude)
    - Returns a random lowercase letter a-z.
    - Excludes any single-character strings provided in exclude.
greaterThan(base)
    - Returns a random integer strictly greater than base.
    - base can be an int or a UIntValue.
    lessThan(base)
        - Returns a random integer strictly less than base.
        - base can be an int or a UIntValue.
    choose((text, value), ...)
        - Randomly selects one option and returns a ChoiceValue with .text and .value.
        - Use .text in question/prompt and .value in Jinja conditionals.
    randomLoop(loopInt, *bodyLines)
        - Returns a randomized C++ loop string using loopInt (for/while).
        - Uses loopInt.operator and loopInt.step to format comparison and increment.
    combinations(formatString, *values, exclude=None)
        - Renders all unique permutations into the Jinja formatString.
        - exclude removes exact matches from the result list.
    loopPrint(formatString, *loopVars)
        - Simulates nested loop execution in true nested order and returns the concatenated output.
        - Supports up to 4 LoopIntValue arguments.
        - Exposes loop variables by their loop name and by template varId if present.

question_library.py VERSION 2.0 POWER UP (3/27)

    UFloat(name, minValue, maxValue, precision)
        - Generates a float randomly between min and maxValue (inclusive-ish).
        - precision defaults to 2 (set to None to disable rounding).
    randomDataType(*exclude)
        - Returns a random data type key string from _DATA_TYPES.
        - Pass type names to exclude (case-insensitive).
    sizeOfCalc(typeName, count)
        - Returns total size in bytes for typeName multiplied by count.
    nameGen()
        - Returns a Name object from the "randomnames" table.
        - Access fields with .first, .middle, .last and render with {{ name }}.
    lines(*parts)
        - Joins the given values with newline characters.
        - Useful for multi-line outputs in answer/incorrect templates.
